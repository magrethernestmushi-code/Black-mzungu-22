# BLACK MZUNGU STUDIO
Private mobile-first vocal studio. Stage A+B: import beat, record vocal takes (from the playhead, with count-in and metronome), edit clips (split, trim, move, duplicate, mute, undo), auto vocal engineer (measures the vocal, then sets high-pass, EQ, sibilance cut, compressor, reverb, tempo delay), Mix Assistant (vocal balance, masking, bass, mono checks), loudness-targeted mastering with lookahead limiter and true-peak ceiling, verified WAV exports (mix, mastered, dry or processed vocal stems). All audio stays in your browser (IndexedDB); nothing is uploaded.
Run `npm test` for DSP tests. Deploy as a static site, publish path `.` (see render.yaml).
Not yet wired into the screen: pitch correction UI (engine done and tested), presets UI (data done), project backup UI (format done), beat maker UI (engine done), MP3 export, loop, separate tracks.
Needs a real-device listening test: latency alignment and recording quality on iPhone.
