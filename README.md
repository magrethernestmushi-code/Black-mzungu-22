# BLACK MZUNGU STUDIO
Private mobile-first vocal studio. Stage A+B: import beat, record vocal takes (from the playhead, with count-in and metronome), edit clips (split, trim, move, duplicate, mute, undo), auto vocal engineer (measures the vocal, then sets high-pass, EQ, sibilance cut, compressor, reverb, tempo delay), export verified WAV mix and dry or processed vocal stems. All audio stays in your browser (IndexedDB); nothing is uploaded.
Run `npm test` for DSP tests. Deploy as a static site, publish path `.` (see render.yaml).
Not yet built: noise reduction, true de-esser, pitch correction, loudness-matched A/B, loop region, drag editing, separate tracks, effects, Mix Assistant, mastering, MP3, project backup file, beat maker.
Needs a real-device listening test: latency alignment and recording quality on iPhone.
