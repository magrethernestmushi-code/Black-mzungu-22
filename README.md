# BLACK MZUNGU STUDIO
Private mobile-first vocal studio. Stage A: import beat, record vocal takes over it, play back, export verified WAV. All audio stays in your browser (IndexedDB); nothing is uploaded.
Run `npm test` for DSP tests. Deploy as a static site, publish path `.` (see render.yaml).
Not yet built: multitrack clip editing, effects, Mix Assistant, mastering, MP3, project backup file, beat maker.
Needs a real-device listening test: latency alignment and recording quality on iPhone.
